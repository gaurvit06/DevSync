# Five-minute demonstration

1. Start the local app and explicitly run `node scripts/seed-demo.mjs`. Sign in as `manager@devsync.test` with the README's demo password.
2. Overview: explain persisted counts, completion, overdue work, workload, and bug severity. Generate a summary and identify its local-fallback label and timestamp.
3. Board: open registration work, read its comment, change its status using the keyboard-accessible select, then show updated dashboard counts.
4. Open the login bug. Inspect reproduction details, request a category suggestion, explain that it has not changed the record, then accept it.
5. Team: invite a newly registered fictional account. In a separate browser profile/incognito session, accept the invitation and show the developer's restricted controls.
6. As developer, add a comment. As manager, open Inbox and mark its notification read. Activity records relevant changes.
7. Stop/start services without deleting volumes and show the records still exist. Open VERIFICATION.md and explain the separation between MySQL/browser tests and unverified live AI credentials.

No live editor or code runner is claimed. This project coordinates development work; it does not execute source code.
